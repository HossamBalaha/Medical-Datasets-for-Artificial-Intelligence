#### 🎭 Segmentation Task Details

- **Task Type**: Fine-grained multiclass semantic segmentation of thoracic anatomy.
- **Number of Classes**: 1️⃣5️⃣9️⃣ distinct anatomical classes (e.g., specific ribs, vertebrae, lung lobes, heart
  chambers, vessels).
- **Annotation Protocol**: High-quality pseudo-labels generated by projecting annotated 3D thorax CT scans onto a 2D
  plane, mimicking traditional X-ray imaging.

#### ⚠️ Usage Considerations

| Aspect                    | Recommendation                                                                                                                          |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| **🔍 Pseudo-Label Noise** | As with any pseudo-labeled dataset, some boundary inaccuracies may exist; consider robust loss functions (e.g., Focal Loss, Dice Loss). |
| **📦 Large Scale**        | 14K+ images and 159 classes require significant computational resources; consider distributed training or patch-based approaches.       |
| **🧪 Class Imbalance**    | Rare anatomical structures will have fewer instances; apply class weighting or oversampling.                                            |

#### 💡 Suggested Preprocessing Pipeline

1. **Parse metadata**: Load the provided JSON label dictionaries and train/val/test split files.
2. **Extract archives**: Decompress the image tarball and label zip file into structured directories.
3. **Standardize geometry**: Resize images and multi-channel masks to uniform dimensions (e.g., 512×512 or 1024×1024).
4. **Intensity normalization**: Scale pixel values to [0, 1] or standardize using dataset-wide statistics.
5. **Augmentation **(training only): Incorporate rotation, flipping, and elastic deformations; apply identical
   transforms to images and multi-class masks.
6. **Evaluation metrics**: Report mean Intersection over Union (mIoU) and mean Dice coefficient across all 159 classes.
